Entity Task Project Documentation

📌 Overview

A C project using SDL 1.2 for game entity management and enemy AI systems.

✨ Features

✅ Entity Management

  • Create, update, and destroy entities
  • Hierarchical entity relationships
  • Enemy initialization and display + ES (Level1/Level2)
  • Enemy random movement (2 trajectories based on game level)
  • Enemy animation (movement, attack)
  • Bounding box collision (Player/Enemy) + collision (Player + ES)
  • Health management (alive, wounded, neutralized) for enemies and display
  • Automatic movement with AI
